# Simple Interest Calculator

A simple Bash script that calculates simple interest based on user input.

## What it does
The script asks for three values and prints the simple interest:
- Principal: the starting amount of money
- Rate of interest: the yearly interest rate, in percent
- Time period: the number of years

## Formula
Simple Interest = (Principal x Rate x Time) / 100

## How to run
Run these two commands in the terminal:

    chmod +x simple-interest.sh
    ./simple-interest.sh

## Example
Principal = 1000, Rate = 5, Time = 2, so Simple Interest = 100
